# Метки триажа

Скиллы говорят о пяти канонических ролях триажа. Этот файл сопоставляет роли со строками меток в трекере этого репозитория.

| Label in mattpocock/skills | Label in our tracker | Смысл                                      |
| -------------------------- | -------------------- | ------------------------------------------ |
| `needs-triage`             | `needs-triage`       | Мейнтейнеру нужно оценить задачу           |
| `needs-info`               | `needs-info`         | Ждём от автора больше информации           |
| `ready-for-agent`          | `ready-for-agent`    | Спека полная, можно отдать AFK-агенту      |
| `ready-for-human`          | `ready-for-human`    | Нужна реализация человеком                 |
| `wontfix`                  | `wontfix`            | Делать не будем                            |

Когда скилл называет роль (например, «apply the AFK-ready triage label»), бери строку метки из колонки `Label in our tracker`.

Колонку `Label in our tracker` правь, если в трекере другие имена.
