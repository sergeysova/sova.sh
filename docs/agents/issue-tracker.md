# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues. Use the `gh` CLI.

- Create: `gh issue create --title "..." --body "..."`
- Read: `gh issue view <number>`
- List: `gh issue list`
- Comment: `gh issue comment <number> --body "..."`
- Edit labels: `gh issue edit <number> --add-label "..."` or `--remove-label "..."`
- Close: `gh issue close <number>`

Infer the repository from the Git remote. PRs are not a triage request surface.
